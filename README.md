# BHAIYU Android app
Open GUIDE.html for the full guide (features, cost, time, steps, commands).

Quick steps:
1. New GitHub repo, upload everything here (keep the .github folder).
2. Optional secrets: OPENAI_KEY and/or GEMINI_KEY (Settings > Secrets and variables > Actions).
3. Actions > Build BHAIYU APK > Run workflow (about 3-6 min).
4. Artifacts > BHAIYU-apk > install app-debug.apk.
5. Pair HC-05 first. In app: Connect > pick HC-05 > Listen.

New: say "BHAIYU ye kya hai" for front-camera vision. Tap Remote to control from a second phone (WiFi page or Bluetooth).
